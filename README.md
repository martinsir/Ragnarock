# Ragnarock

Ragnarock was our first school team project during the Computer Science programme.

The goal of the project was to design and develop a website for the Rockmuseet. The project gave us our first practical experience with planning, designing and developing a complete web application while working together as a team.

## About the project

The website was created as part of our first school project.

We worked with:

- Website structure and navigation
- Responsive design
- Styling and layout
- Presenting museum content
- Team collaboration
- Git and version control

## Technologies

The project was developed using technologies such as:

- C#
- ASP.NET
- HTML
- CSS
- JavaScript
- Git / GitHub

## My contribution

This was a collaborative project, and the repository contains work from multiple team members.

My work included:

- Front-end development
- Styling and layout
- Implementing parts of the website
- Fixing and improving existing functionality
- Git collaboration and version control

## Project context

This was our first larger project during the Computer Science education and was primarily focused on learning how to work together on a software project from initial planning to implementation.
